# index.html 里原来的那些注释（2026-10-13 搬出来的）

用户要求：**发出去的页面里不能有注释**（他在浏览器「元素」面板里翻到觉得别扭）。
而这些注释是留给维护的（为什么这么做、踩过什么坑），删了就没了 —— 所以整块搬到这里。

⚠️ **改 `index.html` 之前先看这个文件**：下面每一条都对应页面上的一处结构。
⚠️ `scripts/build.mjs` 里还有一道兜底（打包 dist 时会再剥一遍注释），别删。
